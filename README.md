# Jira Alternative

Personal project tracker built on Cloudflare's edge stack.

## Tech Stack
- **Runtime:** Cloudflare Workers
- **Framework:** Hono
- **Database:** Cloudflare D1 (SQLite)
- **Language:** TypeScript
